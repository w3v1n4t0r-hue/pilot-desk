When to use this calculation

Performance math helps explain relationships, but it does not replace an AFM or POH performance chart. Use the result to study, cross-check, or estimate, then verify aircraft-specific takeoff, landing, climb, stall, glide, or limitation data in the current approved source.

This accelerated stall speed page accepts 1-G stall speed, Bank angle and returns Stall speed, Load factor, Increase. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: 1-G stall speed 50 kt; Bank angle 60 deg. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Accelerated stall speed = 1-G stall speed × √load factor.

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Do not assume a generic equation includes aircraft-specific corrections, manufacturer interpolation procedures, regulatory reserves, runway factors, or operating limitations unless the page explicitly says so.

Common questions

Why does stall speed increase in a level turn?

In a coordinated level turn, load factor increases with bank angle. Stall speed increases approximately with the square root of load factor when configuration is otherwise unchanged.

Does bank angle alone always determine stall speed?

No. Configuration, load factor, maneuvering, turbulence, and aircraft-specific characteristics matter. The calculator models a coordinated level-turn relationship.

Where should I get actual stall speeds?

Use the current aircraft POH or AFM and applicable operating guidance.
