When to use this calculation

Use this tool while building or checking a flight-planning problem. It is especially useful for quick scenario checks, classroom work, and comparing how a change in one input changes the result. Keep winds, fuel, time, and aircraft limits tied to current source data rather than treating a calculator result as a dispatch decision.

This holding leg distance page accepts Groundspeed, Leg time and returns Leg distance, NM per minute, Feet traveled. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Groundspeed 120 kt; Leg time 60 sec. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.
