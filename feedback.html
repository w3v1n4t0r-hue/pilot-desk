FEEDBACK

Report a problem or idea.

If something in PilotDesk looks wrong, especially a formula, unit, weather display, airport record, or safety message, report it so it can be checked.

Safety-critical problem? Stop relying on the affected PilotDesk output and verify the information independently before continuing flight planning or operation.

Before posting

Submitting opens GitHub so you can review the report before it is posted. GitHub issues may be public. Do not include passwords, passenger names, private personal information, tail numbers you do not want public, or sensitive security exploit details.

Security issue? If the repository Security tab offers Report a vulnerability, use that private reporting option. If it does not, open only a minimal public issue asking for a private channel and leave exploit details out. See the repository security policy for the full reporting guidance.

For a calculation problem, include the calculator name, units, entered values if they are not sensitive, expected result, and the result PilotDesk showed. For weather or airport data, include the station identifier and approximate time you saw the problem.

PilotDesk feedback is not an emergency channel and is not continuously monitored.
