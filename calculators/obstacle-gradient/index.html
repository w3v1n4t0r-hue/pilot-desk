How to use this calculator

Use this math as a quick check or study aid. Takeoff, landing, climb, stall, glide, and limitation data still come from the current POH or AFM for the aircraft.

Enter Obstacle height above runway, Horizontal distance, Desired margin. The calculator returns Required gradient, Percent grade, Angle. Check the inputs before relying on the result.

Quick check

The sample values are: Obstacle height above runway 500 ft; Horizontal distance 2 NM; Desired margin 50 ft. Run the calculation, change one input, and run it again to see how the result changes. For a real flight, replace the sample values with current information and check the result against the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Obstacle Climb Gradient uses the entered values to compute the outputs shown above using standard arithmetic and aviation relationships.

Units are shown beside each field and result. Aircraft-specific corrections, interpolation rules, reserves, runway factors, and operating limits are not included unless the page says they are.
