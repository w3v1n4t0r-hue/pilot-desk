How to use the Percent MAC calculator

Percent MAC: Use the exact aircraft’s arms, current empty-weight data and approved envelope. A correct calculation alone cannot show whether loading is within limits.

Inputs

  • CG location — enter the value in in.
  • LEMAC — enter the value in in.
  • MAC length — enter the value in in.

Formula and method

Percent MAC = (CG − LEMAC) ÷ MAC length × 100.

What the result means

Percent MAC: Fuel burn can change weight and moment as well as total weight. Check CG against the correct envelope at every required point.

Common mistakes to avoid

Percent MAC check: Use arms measured from the same datum and weight and moment values from the records for that aircraft.
