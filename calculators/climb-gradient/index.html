How to use the Climb Gradient to FPM calculator

Enter the required climb gradient and groundspeed to find the vertical speed needed over the ground.

Inputs

  • Gradient — enter the value in ft/NM.
  • Groundspeed — enter the value in kt.

Formula and method

Vertical speed (ft/min) = climb gradient (ft/NM) × groundspeed (NM/min).

What the result means

The FPM result is the climb rate needed to meet the entered ft/NM at that groundspeed. Compare aircraft capability using current performance data.

Common mistakes to avoid

A climb rate in feet per minute is not the same as a climb gradient. Gradient changes with groundspeed even when vertical speed stays constant.
