How to use the Obstacle Climb Gradient calculator

Enter obstacle height, any desired clearance margin, and horizontal distance. Keep all distance units consistent.

Inputs

  • Obstacle height above runway — enter the value in ft.
  • Horizontal distance — enter the value in NM.
  • Desired margin — enter the value in ft.

Formula and method

Required geometric gradient = obstacle height plus desired margin ÷ horizontal distance, with consistent units.

What the result means

The answer is the geometric climb gradient needed to gain the entered height over the entered distance. It does not establish that an aircraft can achieve it.

Common mistakes to avoid

Use the correct obstacle reference and add the margin required by the applicable procedure or planning method. Confirm performance with approved aircraft data.
