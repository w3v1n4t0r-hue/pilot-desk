How to use the NM per Minute calculator

Enter groundspeed in knots to see the distance traveled each minute and the time needed for one nautical mile.

Inputs

  • Groundspeed — enter the value in kt.

Formula and method

Nautical miles per minute = groundspeed in knots ÷ 60.

What the result means

This is a quick mental-math bridge between speed and distance. It can help estimate timing, but not account for turns or changing groundspeed.

Common mistakes to avoid

Knots are nautical miles per hour. Divide by 60 for NM per minute; do not read the knot value as distance per minute.
