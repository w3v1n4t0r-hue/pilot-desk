How to use this calculator

Use this for planning math and cross-checks. Verify current wind, variation, coordinates, and navigation data before using the result for a flight.

Enter Latitude 1, Longitude 1, Latitude 2, Longitude 2. The calculator returns Distance, Initial bearing, Statute miles. Check the inputs before relying on the result.

Quick check

The sample values are: Latitude 1 47.95 deg; Longitude 1 -97.18 deg; Latitude 2 46.92 deg; Longitude 2 -96.81 deg. Run the calculation, change one input, and run it again to see how the result changes. For a real flight, replace the sample values with current information and check the result against the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Great-Circle Distance uses the entered values to compute the outputs shown above using standard arithmetic and aviation relationships.

Units are shown beside each field and result. Aircraft-specific corrections, interpolation rules, reserves, runway factors, and operating limits are not included unless the page says they are.
