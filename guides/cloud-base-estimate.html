Estimating cloud base from temperature and dew point

A common pilot weather shortcut estimates the base of convective clouds from the spread between surface temperature and dew point. It is useful for understanding the relationship between temperature, moisture and rising air, but it is not a replacement for an observed or forecast ceiling.

The quick estimate

Using Celsius, subtract dew point from temperature and multiply the spread by roughly 400 feet. The result is an approximate cloud-base height above ground level. A 5°C spread gives an estimate near 2,000 feet AGL.

Worked example

If the temperature is 24°C and the dew point is 14°C, the spread is 10°C. Multiplying by 400 gives an estimated convective cloud base near 4,000 feet AGL. This is a rough thermodynamic estimate, not a measured ceiling.

Why the shortcut works

As unsaturated air rises, it cools faster than its dew point changes. When temperature and dew point converge, the air approaches saturation and visible cloud can form. The shortcut approximates the height where that convergence occurs.

Important limitations

Frontal cloud layers, inversions, precipitation, terrain, advection, multiple cloud decks and other atmospheric processes can make the shortcut inaccurate. An airport METAR ceiling is based on reported cloud coverage and height, not on this formula.

Use it as a reasonableness check

The estimate is most useful as a learning tool or cross-check alongside current METARs, TAFs and official weather products. If the calculated value and observed weather disagree, use the actual observations and forecasts.
