How to use the 2% Rule TAS Estimate calculator

Use the result as a math check or training reference. Aircraft performance, limitations and operating decisions still come from the current POH or AFM, applicable charts and the conditions that actually exist.

This page is built around CAS, Pressure altitude. Enter the values, calculate, and then check whether Approx. TAS, Increase over CAS, CAS are reasonable before carrying them into another planning step.

Inputs

  • CAS — enter the value in kt.
  • Pressure altitude — enter the value in ft.

Formula and method

The 2% rule estimates TAS by increasing CAS about 2% per 1,000 feet. It is a training shortcut, not a precision air-data solution.

The calculator keeps the arithmetic visible so it can be used as more than a black-box answer. If you are studying for an oral exam or reviewing a navlog, work the relationship once by hand and use PilotDesk as the cross-check.

Worked example setup

The default example uses CAS 110 kt; Pressure altitude 8000 ft. Calculate the example first, then change one input at a time. Watching which result changes—and by how much—is a quick way to understand the relationship instead of memorizing a single answer.

What the result means

Performance math describes relationships, not guarantees. Weight, configuration, runway condition, wind, temperature, technique and aircraft-specific data can all change the operational answer.

Common mistakes to avoid

Common errors include using the wrong weight or configuration, confusing indicated and true airspeed, applying a training shortcut outside its assumptions, or treating a calculated estimate as an aircraft limitation.

Do a reasonableness check after every calculation. A mathematically valid result can still be unusable if the wrong source value, unit, reference or aircraft data was entered.
