How to use the DME Arc Distance calculator

DME Arc Distance: Check true and magnetic references before comparing the result with a chart. Use current navigation data for a flight.

Inputs

  • DME radius — enter the value in NM.
  • Arc swept — enter the value in deg.

Formula and method

Arc length equals the selected fraction of a circle multiplied by the circumference at the entered DME radius.

What the result means

Arc distance: A result can be arithmetically right and still miss the route if its reference or coordinates are wrong.

Common mistakes to avoid

DME Arc Distance check: Check east/west signs, true or magnetic references, and rounding before relying on a direction or distance.
