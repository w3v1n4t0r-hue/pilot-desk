How to use the Obstacle Climb Gradient calculator

Obstacle Climb Gradient: Use the result as a math check or training reference. Aircraft performance, limitations and operating decisions still come from the current POH or AFM, applicable charts and the conditions that actually exist.

Inputs

  • Obstacle height above runway — enter the value in ft.
  • Horizontal distance — enter the value in NM.
  • Desired margin — enter the value in ft.

Formula and method

Required geometric gradient = obstacle height plus desired margin ÷ horizontal distance, with consistent units.

What the result means

Required gradient: Performance math describes relationships, not guarantees. Weight, configuration, runway condition, wind, temperature, technique and aircraft-specific data can all change the operational answer.

Common mistakes to avoid

Obstacle Climb Gradient check: Common errors include using the wrong weight or configuration, confusing indicated and true airspeed, applying a training shortcut outside its assumptions, or treating a calculated estimate as an aircraft limitation.

Sources and limitations

The Obstacle Climb Gradient calculation uses the aviation relationship shown above. Aircraft-specific limitations, performance and procedures still come from the current approved source for the airplane or operation. See PilotDesk sources and methods.

Obstacle Climb Gradient questions

What does the Obstacle Climb Gradient calculator do?

It uses the entered aviation values to solve the obstacle climb gradient relationship and displays the main outputs immediately for study, planning and cross-checking.

What inputs should I use?

For Obstacle Climb Gradient, use values from the current source that applies to the problem. Keep the units and reference systems consistent with the performance relationship being solved.

Can I use the result as the only source for a flight?

No. Treat the Obstacle Climb Gradient result as a calculation and training cross-check. Operational decisions still require the current aircraft data, weather, charts, procedures and regulations that apply.
