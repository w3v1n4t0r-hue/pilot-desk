Pilot navigation reference

Navigation planning connects direction, wind, speed, distance, time and position. This reference groups PilotDesk's navigation guides so the individual formulas fit into one workflow instead of being isolated calculator answers.

Course, heading and track

Course, heading and track explains the basic terms. True versus magnetic heading covers variation, while reciprocal headings covers the 180-degree relationship.

Wind planning

Wind triangle and wind correction angle explain why a pilot must point into a crosswind to maintain course. Groundspeed versus airspeed explains which speed belongs in ETA calculations.

Time and distance

Time, speed and distance covers the core formulas. NM per minute turns groundspeed into quick mental math for ETA, holding and descent planning.

Coordinates and route geometry

DMS and decimal coordinates explains latitude and longitude formats. Great-circle distance explains shortest-path geometry between two coordinates.

Instrument-navigation geometry

DME arc distance explains arc length from radius and degrees flown. Holding leg distance connects groundspeed and timed legs.

Building a navlog

VFR navlog planning ties course, wind, heading, groundspeed, time and fuel together. PilotDesk's route planner and online E6B provide interactive tools for the same relationships.

Airport orientation

Runway numbers and headings explains magnetic runway designators, while airport identifiers covers ICAO, FAA and IATA code systems.

How Pilot navigation reference fits into pilot training

A pilot navigation reference for course, heading, track, wind correction, groundspeed, DME arcs, coordinates, navlogs and route math.

Use this reference as part of a larger planning or training workflow. Identify the source of each input, keep units consistent, estimate the expected range, and then compare the result with the current aircraft, weather, chart or procedural information that governs the real operation.

A practical way to study this topic

Start by naming the quantity you are trying to find and the units it should have. Write down the source of each input, make a rough mental estimate, and then work the relationship. If the calculated answer is far outside the estimate, check units, signs, direction references and whether the formula assumes groundspeed, true airspeed, indicated airspeed, pressure altitude or another specific value.

For an actual flight, finish the process by comparing the training result with the current source that controls the operation. That may be the aircraft POH or AFM, an FAA or charting publication, current airport data, official weather, ATC instructions, or an operator procedure. The purpose of the math is to improve understanding and cross-checking—not to replace those sources.
