This matrix is the authoring and study map for PilotDesk. A live question must trace to the applicable ACS or PTS task, an FAA or aircraft source, and—when the FAA uses one—the official testing-supplement figure.

Coverage is not a readiness certificate. A green or completed topic only describes PilotDesk study coverage. Current FAA standards, regulations, procedures, and aircraft-approved data remain controlling.

QUESTION AUTHORING GATE

Volume does not count as coverage.

01Standard first

Start with an ACS/PTS area, task, or knowledge element. Do not write a generic aviation question and assign a code afterward.

02Use the controlling source

Regulation, AIM, FAA handbook, current chart/procedure, or POH/AFM material must support the answer.

03Use the FAA figure

If the FAA tests the subject with a chart, diagram, table, or procedure, PilotDesk should train with that same official figure family.

04Review every distractor

Wrong choices need a realistic misconception, chart-reading error, rule mix-up, or calculation mistake—not random nearby values.
