When to use this calculation

Use this tool while building or checking a flight-planning problem. It is especially useful for quick scenario checks, classroom work, and comparing how a change in one input changes the result. Keep winds, fuel, time, and aircraft limits tied to current source data rather than treating a calculator result as a dispatch decision.

This fuel required page accepts Fuel on board, Fuel burn, Trip time, Reserve and returns Required fuel, Trip fuel, Fuel margin after reserve. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Fuel on board 50 gal; Fuel burn 10 gal/hr; Trip time 2.5 hr; Reserve 45 min. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Fuel Required uses the entered values to compute the outputs shown above using standard arithmetic and aviation relationships.

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Do not assume a generic equation includes aircraft-specific corrections, manufacturer interpolation procedures, regulatory reserves, runway factors, or operating limitations unless the page explicitly says so.

Common questions

What does this fuel calculator include?

It adds trip fuel and the entered reserve fuel, then compares the requirement with fuel on board.

Does the reserve box automatically know the legal reserve?

No. You enter the reserve. Determine the applicable regulatory and operational fuel requirements for the flight before using the result.

Should I use planned or actual fuel burn?

Use aircraft-specific approved or otherwise appropriate planning data, adjusted as required by the operating situation.
