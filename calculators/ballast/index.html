How to use the Ballast Required calculator

Ballast Required: Use the exact aircraft’s arms, current empty-weight data and approved envelope. A correct calculation alone cannot show whether loading is within limits.

Inputs

  • Current weight — enter the value in lb.
  • Current CG — enter the value in in.
  • Target CG — enter the value in in.
  • Ballast arm — enter the value in in.

Formula and method

The ballast equation balances the existing aircraft moment against the target CG and selected ballast arm.

What the result means

Ballast required: Fuel burn can change weight and moment as well as total weight. Check CG against the correct envelope at every required point.

Common mistakes to avoid

Ballast Required check: Use arms measured from the same datum and weight and moment values from the records for that aircraft.
