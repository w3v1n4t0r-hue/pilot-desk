When to use this calculation

Performance math helps explain relationships, but it does not replace an AFM or POH performance chart. Use the result to study, cross-check, or estimate, then verify aircraft-specific takeoff, landing, climb, stall, glide, or limitation data in the current approved source.

This dynamic hydroplaning speed page accepts Tire pressure and returns Hydroplaning speed, Tire pressure, Formula. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Tire pressure 36 psi. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Dynamic hydroplaning speed estimate ≈ 9 × √tire pressure (psi).

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Common questions

What is the dynamic hydroplaning rule of thumb?

A commonly taught estimate for minimum dynamic hydroplaning speed is about 9 times the square root of tire pressure in psi, producing a speed in knots.

Is this a guaranteed hydroplaning speed?

No. Runway condition, tire condition, water depth, braking, and other factors matter. Treat it as an educational estimate, not a go/no-go value.

Where should runway decisions come from?

Use current runway-condition information, aircraft guidance, airport data, and applicable operational procedures.
