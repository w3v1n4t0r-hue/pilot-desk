Built around source visibility

FAA chart tiles remain FAA-hosted and are not stored as an offline chart database by PilotDesk. FAA terminal procedures remain links to the original FAA PDFs. Current AWC weather is requested through PilotDesk's same-origin server endpoint and is never intentionally served from the offline cache. Aircraft-specific performance still comes from the current approved data applicable to the airplane.
