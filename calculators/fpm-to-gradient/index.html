Use the FPM to Climb Gradient calculator

FPM to Climb Gradient uses Vertical speed, Groundspeed to calculate Gradient, Percent grade, Climb angle. Enter values from the source that applies to the problem, calculate, then compare the result with a rough estimate before you use it anywhere else.

Inputs

  • Vertical speed — enter the value in fpm.
  • Groundspeed — enter the value in kt.

Formula

Climb gradient (ft/NM) = vertical speed (ft/min) ÷ groundspeed (NM/min).

The example starts with Vertical speed 500 fpm; Groundspeed 90 kt. Change one input at a time and watch which output moves. That is usually more useful for training than memorizing one sample answer.
