True versus magnetic heading

A charted course can be referenced to true north while a magnetic compass responds to magnetic north. The angular difference between those references is magnetic variation, and pilots account for it when converting between true and magnetic directions.

True direction

True course or heading is measured relative to geographic true north. Lines of longitude converge on the geographic poles, so true direction is the natural reference for many chart and navigation calculations.

Magnetic direction

Magnetic heading is referenced to Earth's magnetic field. Because magnetic north is not in the same location as true north, the difference varies by location and changes slowly over time. Aeronautical charts depict variation with isogonic information.

East and west variation

A common memory aid is “east is least, west is best” when converting true to magnetic: subtract easterly variation and add westerly variation. When converting in the opposite direction, reverse the operation. The safest method is to write the equation and keep the sign convention consistent instead of relying only on memory.

Worked example

If true course is 090° and local variation is 10° east, magnetic course is approximately 080°. If variation were 10° west instead, magnetic course would be about 100°.

Variation is not deviation

Variation is the difference between true and magnetic north. Compass deviation is error created by magnetic influences inside the aircraft. Traditional navigation workflows account for both, but they are different corrections.
