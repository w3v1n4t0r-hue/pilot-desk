How to use the Turn Radius calculator

Turn Radius: Use the result to understand the geometry and relationships behind common flight-training maneuvers. The calculated number is not a substitute for aircraft limitations, instructor guidance or the applicable training standard.

This page is built around True airspeed, Bank angle. Enter the values, calculate, and then check whether Turn radius, Turn diameter, Rate of turn are reasonable before carrying them into another planning step.

Inputs

  • True airspeed — enter the value in kt.
  • Bank angle — enter the value in deg.

Formula and method

Coordinated turn radius is determined by true airspeed and bank angle.

For Turn Radius, work the relationship once by hand and compare it with the displayed result. That makes the calculator useful for checking the arithmetic without turning it into a black-box answer.

Worked example setup

The default example uses True airspeed 120 kt; Bank angle 30 deg. Calculate the example first, then change one input at a time. Watching which result changes—and by how much—is a quick way to understand the relationship instead of memorizing a single answer.

What the result means

Turn radius: These outputs make the speed-bank-load-factor relationships visible. They are especially useful for oral-exam preparation and for checking whether a mental estimate is in the right range.

Common mistakes to avoid

Turn Radius check: Common errors include using indicated airspeed where a formula expects true airspeed, assuming bank angle alone describes every maneuver, or ignoring how wind changes groundspeed-dependent relationships.

Before using the Turn Radius result elsewhere, compare Turn radius with a rough estimate and recheck the source and units for True airspeed.
