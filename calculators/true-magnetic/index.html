Convert the direction reference

Magnetic variation is entered as east-positive and west-negative. From true to magnetic, subtract the signed variation; from magnetic to true, add it. The calculator converts a direction only—it does not convert course into heading or account for wind drift.

True → magnetic: M = T − variation
Magnetic → true: T = M + variation

Worked examples

With 10° east variation (+10°), 090° true becomes 080° magnetic: 090 − (+10) = 080. With 10° west variation (−10°), 090° true becomes 100° magnetic: 090 − (−10) = 100. This east-subtract / west-add check catches the common sign reversal.

Course describes an intended ground path; heading is the direction the nose points; track is the path made over the ground. Use wind correction separately when finding heading for a desired track. Direction references must match: the wind triangle here uses true course and true wind. Variation changes with location and time, so use current charted/navigation data rather than a memorized value.

Practice with the true versus magnetic guide and wind triangle. See the FAA Pilot's Handbook of Aeronautical Knowledge and PilotDesk sources and methods.

True / Magnetic Heading questions

What does the True / Magnetic Heading calculator do?

It uses the entered aviation values to solve the true / magnetic heading relationship and displays the main outputs immediately for study, planning and cross-checking.

What inputs should I use?

For True / Magnetic Heading, use values from the current source that applies to the problem. Keep the units and reference systems consistent with the navigation relationship being solved.

Can I use the result as the only source for a flight?

No. Treat the True / Magnetic Heading result as a calculation and training cross-check. Operational decisions still require the current aircraft data, weather, charts, procedures and regulations that apply.
