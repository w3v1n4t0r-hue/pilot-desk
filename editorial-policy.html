Editorial, Testing & Corrections Policy

PilotDesk is built as a supplemental aviation planning and training resource. Accuracy, traceability and clear limits matter more than making a tool look authoritative. The goal is to show the relationship being calculated, identify the source or method behind it, test representative cases, and make it easy to report a problem.

Primary-source preference

When an aviation statement depends on a published reference, PilotDesk prefers primary sources such as FAA handbooks, the Aeronautical Information Manual, Aviation Weather Center data, FAA aeronautical data, and current aircraft POH/AFM information. A summary page never overrides the current controlling source.

See Sources & Methods for the main references used across the site.

Calculator review

Calculator formulas are kept in testable source files. Representative inputs and expected outputs are checked automatically before production changes are accepted. Automated checks also verify generated calculator pages, site links, search metadata, structured data, and other site wiring. These checks reduce avoidable errors but do not turn a general-purpose web calculator into approved aircraft data.

Operational boundaries

PilotDesk calculators and guides are for education, planning support and cross-checking. For actual flight operations, pilots should use the current approved data and official sources applicable to the aircraft, route, weather, procedure and operator. Aircraft-specific limitations, performance tables, loading data and procedures always take priority over generic formulas or rules of thumb.

Rules of thumb are labeled

Where a common pilot shortcut is shown, PilotDesk attempts to identify it as an approximation or training rule rather than presenting it as an exact physical model. Examples include simplified pressure-altitude, true-airspeed, cloud-base, hydroplaning and descent-rate relationships.

Corrections

If a formula, explanation, link, source note or result appears wrong, outdated or misleading, users can report it. Safety-related corrections receive priority. A confirmed problem should be corrected in the source, covered by an appropriate regression check when practical, and then deployed through the normal QA process.

Transparency

PilotDesk maintains a public code repository so the project, changes and testing workflow can be inspected independently: PilotDesk on GitHub ↗.

Advertising and independence

Advertising helps support the site. Advertising does not determine calculator formulas, aviation source selection, safety language, or whether a correction is accepted. PilotDesk does not sell placement inside its aviation formulas or source methodology.

Review date

Policy reviewed September 2026. Aviation publications and web services can change; current official sources remain controlling.
