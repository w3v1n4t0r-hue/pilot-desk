When to use this calculation

Performance math helps explain relationships, but it does not replace an AFM or POH performance chart. Use the result to study, cross-check, or estimate, then verify aircraft-specific takeoff, landing, climb, stall, glide, or limitation data in the current approved source.

This fpm to climb gradient page accepts Vertical speed, Groundspeed and returns Gradient, Percent grade, Climb angle. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Vertical speed 500 fpm; Groundspeed 90 kt. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Climb gradient (ft/NM) = vertical speed (ft/min) ÷ groundspeed (NM/min).

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Do not assume a generic equation includes aircraft-specific corrections, manufacturer interpolation procedures, regulatory reserves, runway factors, or operating limitations unless the page explicitly says so.

References and verification

General background for these relationships is available in FAA pilot-training publications such as the Pilot’s Handbook of Aeronautical Knowledge and Airplane Flying Handbook.
