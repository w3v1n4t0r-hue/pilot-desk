Sources & Methods

PilotDesk is built around standard aviation math, physics relationships and public aviation references. The source behind an aircraft-specific limitation or performance number is still the current approved POH/AFM, supplements, placards, operating limitations and other applicable approved material for that aircraft.

Primary aviation references

How the calculators are built

Some PilotDesk tools use direct geometric or physical relationships. Others intentionally use common pilot-training approximations. Inputs are validated and calculations are designed to fail closed when a result would be mathematically undefined or misleading.

Tool familyMethod
Wind componentsTrigonometric resolution of reported wind relative to a runway or course.
Wind triangleVector solution for heading, groundspeed and wind-correction angle; impossible steady solutions are rejected.
Density altitudeDry-air ISA atmosphere model using pressure altitude and temperature. It is not an aircraft-performance calculation.
Pressure altitudeCommon pilot approximation using field elevation and the difference from 29.92 inHg.
Turns and load factorCoordinated level-turn geometry and load-factor relationships.
Accelerated stallStall speed scaled by the square root of load factor.
Pivotal altitudeCommon knots/feet approximation: groundspeed² ÷ 11.3.
HydroplaningCommon dynamic-hydroplaning rule of thumb: approximately 9 × √tire pressure in knots.
Maneuvering-speed adjustmentSquare-root weight relationship, used only below the reference published weight.
Weight & balanceMoment = weight × arm; CG = total moment ÷ total weight. PilotDesk does not infer an approved CG envelope unless the user has authoritative aircraft data.
3° descent / climb gradientsGeometric flight-path relationships plus clearly labeled pilot rules of thumb where shown.
2% TAS estimateTraining shortcut only, not a precision true-airspeed solution.

Live weather

Weather requests are sent through a PilotDesk server endpoint to the Aviation Weather Center. Raw METAR and TAF text is shown as returned when available. Airport/runway wind components are derived from the available airport metadata and current reported wind; runway headings displayed by PilotDesk are approximate and should be checked against current published airport information.

PilotDesk weather is not an official weather briefing and does not include every item required for a flight. Pilots remain responsible for current NOTAMs, TFRs, forecasts, weather, runway status, regulations and other information applicable to the operation.

Corrections and versioning

If a formula, source, explanation or output appears wrong or outdated, report it. Safety-related corrections are treated as higher priority than feature requests. PilotDesk also runs automated calculator and site checks when the production code changes.

Government and third-party sources control their own content, availability and revision cycles. A link from PilotDesk does not mean the source endorses PilotDesk.
