Import a checklist

Use one item per line. The cleanest format is Challenge — Response. All-caps lines can be used as section headings. PilotDesk preserves item order and does not invent or reorder checklist actions.

TXT, Markdown, CSV and simple JSON are read locally in your browser. For PDF/image checklists, paste or export the text first so PilotDesk does not guess at safety-critical wording.

Training design

Checklist order matters. PilotDesk never shuffles checklist items. Flow Trainer can hide the response so a student recalls the action before revealing it, while Checklist mode reads the complete challenge-response item. Progress is stored locally on this device.

Important: this is a training aid, not a replacement for the current aircraft checklist, POH/AFM, QRH, operator manual, instructor guidance, or required cockpit procedures.
