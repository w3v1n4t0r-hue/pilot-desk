When to use this calculation

Use this tool while building or checking a flight-planning problem. It is especially useful for quick scenario checks, classroom work, and comparing how a change in one input changes the result. Keep winds, fuel, time, and aircraft limits tied to current source data rather than treating a calculator result as a dispatch decision.

This endurance & range page accepts Usable fuel, Fuel burn, Groundspeed, Reserve and returns Usable endurance, Maximum endurance, Range after reserve. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Usable fuel 50 gal; Fuel burn 10 gal/hr; Groundspeed 120 kt; Reserve 45 min. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Endurance & Range uses the entered values to compute the outputs shown above using standard arithmetic and aviation relationships.

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Do not assume a generic equation includes aircraft-specific corrections, manufacturer interpolation procedures, regulatory reserves, runway factors, or operating limitations unless the page explicitly says so.

References and verification

General background for these relationships is available in FAA pilot-training publications such as the Pilot’s Handbook of Aeronautical Knowledge and Airplane Flying Handbook.
