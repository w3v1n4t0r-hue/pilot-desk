3° Descent Rate

A three-degree flight path is common in approach and descent planning. The required vertical speed depends on groundspeed: the faster the airplane moves over the ground, the faster it must descend to stay on the same angle.

Quick rule

Vertical speed ≈ groundspeed × 5

At 120 kt groundspeed, the quick estimate is about 600 fpm. PilotDesk also calculates the geometric value using a 3° angle, so you can compare the shortcut with the more exact result.

Distance rule

Another useful planning estimate is roughly 3 NM of descent for each 1,000 ft of altitude to lose. That is a planning shortcut, not a substitute for a published procedure or stabilized-approach criteria.

Worked example

At 120 knots groundspeed, the common cockpit shortcut is 120 × 5, or about 600 feet per minute. The trigonometric value for an exact 3° path is about 636 feet per minute. The shortcut is easy to do mentally; the exact calculation is useful when you want a tighter cross-check.

Groundspeed is the input that matters

A headwind or tailwind changes groundspeed and therefore changes the vertical speed needed to hold the same path angle. At 90 knots the quick estimate is about 450 feet per minute; at 150 knots it is about 750. Recheck the number when groundspeed changes substantially during descent.

Distance check

A 3° path is close to 3 nautical miles for every 1,000 feet you need to lose. That is a planning shortcut, not clearance to descend and not a substitute for published procedure restrictions.

Why the groundspeed × 5 shortcut is close

The exact geometry of a 3° path works out to a little more than five times groundspeed when the answer is expressed in feet per minute. That is why the cockpit rule is fast and usually close enough for a first estimate. The exact value and the shortcut separate more as groundspeed rises, so the calculator is useful when you want a tighter planning number or a quick reasonableness check.
