When to use this calculation

Navigation calculations are useful for planning, classroom problems, and cross-checking another source. Magnetic variation, wind, coordinates, timing, and navigation data can change or be entered incorrectly, so verify operational navigation against current approved data.

This true / magnetic heading page accepts Direction value, Variation (east + / west −) and returns If entered value is TRUE → magnetic, If entered value is MAGNETIC → true, Variation entered. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Direction value 270 °; Variation (east + / west −) 8 °. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.
