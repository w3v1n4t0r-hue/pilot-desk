When to use this calculation

Weight-and-balance math is only one part of determining whether an aircraft loading is acceptable. PilotDesk can calculate moments, CG relationships, ballast math, and conversions, but only the aircraft’s current approved envelope and loading information can determine whether a specific loading is within limits.

This moment & cg page accepts Station weight, Station arm, Total moment, Total weight and returns Station moment, Total CG, Moment / 1000. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: Station weight 180 lb; Station arm 85 in; Total moment 180000 lb-in; Total weight 2200 lb. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Moment = weight × arm; center of gravity = total moment ÷ total weight.

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Do not assume a generic equation includes aircraft-specific corrections, manufacturer interpolation procedures, regulatory reserves, runway factors, or operating limitations unless the page explicitly says so.

References and verification

General background for these relationships is available in FAA pilot-training publications such as the Pilot’s Handbook of Aeronautical Knowledge and Airplane Flying Handbook. For real operations, the controlling source is the current approved information applicable to the aircraft and flight. See PilotDesk Sources & Methods →
