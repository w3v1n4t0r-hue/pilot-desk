How the sequence works

Wind changes heading and groundspeed. Groundspeed changes ETE. ETE changes trip fuel. The same groundspeed changes the vertical speed needed to hold a selected descent gradient. This is why flight-planning math is more useful as a connected sequence than as isolated formulas.
