Flight path angle versus climb gradient

A climb or descent path can be described several ways: as an angle in degrees, a percent gradient, or vertical feet gained or lost per nautical mile. These measurements describe similar geometry but use different units.

Angle in degrees

A flight path angle measures the angle between the flight path and the horizontal. A familiar example is a 3° descent path.

Percent gradient

Percent gradient compares vertical change with horizontal distance. A 5 percent gradient means roughly 5 units of vertical change for every 100 units of horizontal travel.

Feet per nautical mile

Aviation departure and obstacle requirements often use feet per nautical mile. Because one nautical mile is about 6,076 feet, a 3° geometric path is roughly 318 feet per nautical mile.

Geometry versus rate

Angle and gradient describe the shape of the path. Feet per minute describes how quickly altitude changes with time. To convert a gradient to FPM, groundspeed must be included.
