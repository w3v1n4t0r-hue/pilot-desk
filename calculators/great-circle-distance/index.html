Use the Great-Circle Distance calculator

Great-Circle Distance uses Latitude 1, Longitude 1, Latitude 2, Longitude 2 to calculate Distance, Initial bearing, Statute miles. Enter values from the source that applies to the problem, calculate, then compare the result with a rough estimate before you use it anywhere else.

Inputs

  • Longitude 1 — enter the value in deg.
  • Latitude 2 — enter the value in deg.
  • Longitude 2 — enter the value in deg.

Formula

Great-circle distance uses spherical geometry to estimate the shortest path between two latitude/longitude points.

Try the default setup

The example starts with Latitude 1 47.95 deg; Longitude 1 -97.18 deg; Latitude 2 46.92 deg; Longitude 2 -96.81 deg. Change one input at a time and watch which output moves. That is usually more useful for training than memorizing one sample answer.
