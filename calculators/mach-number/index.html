How to use this calculator

Use current pressure, temperature, and weather data. If the number affects a flight, check it against the aircraft performance information and current weather products you are using.

Enter True airspeed, Temperature. The calculator returns Mach, Local speed of sound, TAS. Check the inputs before relying on the result.

Quick check

The sample values are: True airspeed 450 kt; Temperature -50 °C. Run the calculation, change one input, and run it again to see how the result changes. For a real flight, replace the sample values with current information and check the result against the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Mach Number uses the entered values to compute the outputs shown above using standard arithmetic and aviation relationships.

Units are shown beside each field and result. Aircraft-specific corrections, interpolation rules, reserves, runway factors, and operating limits are not included unless the page says they are.
