How to use the Wind Triangle calculator

Use the calculator to work a flight-planning problem, verify hand calculations, or build an example for training. Start with current, correctly referenced inputs and keep runway, wind, course, speed, time and fuel units consistent.

This page is built around True course, True airspeed, Wind from, Wind speed. Enter the values, calculate, and then check whether Heading, Groundspeed, WCA are reasonable before carrying them into another planning step.

Inputs

  • True course — enter the value in deg.
  • True airspeed — enter the value in kt.
  • Wind from — enter the value in deg.
  • Wind speed — enter the value in kt.

Formula and method

The wind triangle resolves the wind vector against the aircraft true-airspeed vector to solve wind-correction angle, heading and groundspeed.

The calculator keeps the arithmetic visible so it can be used as more than a black-box answer. If you are studying for an oral exam or reviewing a navlog, work the relationship once by hand and use PilotDesk as the cross-check.

Worked example setup

The default example uses True course 90 deg; True airspeed 120 kt; Wind from 150 deg; Wind speed 20 kt. Calculate the example first, then change one input at a time. Watching which result changes—and by how much—is a quick way to understand the relationship instead of memorizing a single answer.

What the result means

The output is most useful when it feeds the next planning step. Wind components affect runway decisions, groundspeed affects time and fuel, and descent or holding math depends on how quickly the airplane moves across the ground.

Common mistakes to avoid

Common errors include mixing true and magnetic directions, using airspeed where groundspeed belongs, entering minutes as decimal hours, or treating a generic reserve as the legal requirement for every operation.

Do a reasonableness check after every calculation. A mathematically valid result can still be unusable if the wrong source value, unit, reference or aircraft data was entered.

Wind Triangle questions

What does a wind triangle solve?

It combines course, true airspeed and wind to solve the heading needed to hold course, the resulting groundspeed and the wind-correction angle.

Why must direction references be consistent?

A true course should be paired with a true wind reference, while magnetic values should be paired consistently. Mixing references can introduce an error roughly equal to local magnetic variation.

What if the entered wind is stronger than the airplane can overcome?

Some combinations have no steady solution for the requested course. PilotDesk warns when the entered crosswind relationship makes the wind-triangle solution impossible.
