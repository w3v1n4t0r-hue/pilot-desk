When to use this calculation

Maneuver calculations are useful for training and visualization. Real aircraft response depends on configuration, weight, turbulence, pilot technique, and aircraft limitations, so use these numbers as study aids rather than targets that override approved procedures.

This standard-rate bank page accepts True airspeed and returns Exact 3°/sec bank, FAA quick estimate, Target turn rate. It is designed to make the arithmetic visible and repeatable so a student, instructor, or pilot can change one value and immediately see the effect. A result can still be wrong if an input is wrong, stale, rounded too aggressively, or taken from the wrong aircraft configuration.

Worked practice setup

A useful way to check the tool is to start with the default practice values: True airspeed 120 kt. Calculate once, note the result, then change a single input and calculate again. That isolates the relationship instead of changing several variables at once. For an actual flight, replace every practice value with current information and compare the answer with the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Exact bank angle solves a 3°/second coordinated turn; the quick estimate shown is approximately 15% of TAS.

PilotDesk may use exact trigonometry or standard planning approximations depending on the tool. Units are shown beside each field and result. Do not assume a generic equation includes aircraft-specific corrections, manufacturer interpolation procedures, regulatory reserves, runway factors, or operating limitations unless the page explicitly says so.

References and verification

General background for these relationships is available in FAA pilot-training publications such as the Pilot’s Handbook of Aeronautical Knowledge and Airplane Flying Handbook.
