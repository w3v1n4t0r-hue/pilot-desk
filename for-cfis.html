Why I built it

I'm working on my CFI right now and recently picked up coding as a hobby. I started building PilotDesk because I wanted my own place for the calculators and training tools I kept reaching for.

I'm still learning, and I've used ChatGPT to help code quite a bit of it. If something feels too AI, awkward, unnecessary, or just not how a pilot would actually use it, please tell me. If you like something, tell me that too. I'm looking for specific feedback on what works, what doesn't, what's missing, and what should probably be removed.

One way to use it in a lesson

Give the student the scenario first. Have them estimate the answer and explain the decision. Then use the tool to check the math. If the result is aircraft-specific or operational, finish with the current POH/AFM, chart, weather source, or regulation that actually controls the decision.

Training aid only. PilotDesk does not replace current FAA publications, approved aircraft data, official weather, charts, NOTAMs, or instructor judgment.
