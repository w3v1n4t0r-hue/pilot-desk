Billing questions

Can I use PilotDesk without paying?

Yes. The core site remains free.

Will existing free features suddenly disappear?

No. Core calculators, weather, route planning, source links, and basic study tools remain available without Pro.

What does Pro add right now?

Manual cloud backup/restore for aircraft and saved flights, plus an ad-free signed-in experience.

How is paid access controlled?

Stripe manages payment and subscription changes. PilotDesk grants paid access only after the server receives a verified subscription event, so changing browser storage or profile fields does not grant Pro access.

Can I cancel or update my card?

Yes. Active paid accounts can open Stripe billing management from the PilotDesk account page.
