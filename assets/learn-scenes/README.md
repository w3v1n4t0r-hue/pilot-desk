# PilotDesk Learn assets

Original procedural 3D assets authored for this preview: field-notebook.glb. Regenerate with node scripts/create-learn-assets.mjs. No third-party model, paid asset, or generated video is included. Canvas page textures are authored in src/scripts/learn-scene.js.

The floating lesson cards were removed at the user’s request. Pages cycle through Weather, Medical factors, Aerodynamics, and Navigation. Page textures are 1536 x 2048 pixels.
