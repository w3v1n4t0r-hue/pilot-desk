ABOUT

Pilot work is scattered across too many tabs.

PilotDesk puts common flight math, airport weather, route planning, aircraft notes, and rating study tools in one browser. The formulas and source links stay visible so you can check the work instead of trusting a mystery answer.

Why I built it

PilotDesk is built by a commercial aviation student and pilot who was already doing this work: planning flights, studying for ratings, checking performance math, decoding weather, and going back to the FAA source when a shortcut was not enough. The goal is not to replace those sources. It is to make the work around them faster and easier to organize.

What PilotDesk is for

Use it when you need a calculator, a quick airport-weather check, a route/navlog, or study material for the next rating. The core tools are free. A free account saves Daily, Written Prep, and profile progress. Pro adds aircraft/saved-flight cloud backup and an ad-free signed-in experience. See the current plans.

Built around real pilot tasks

The site focuses on the things pilots repeatedly work through: wind components, density altitude, time-speed-distance, fuel planning, descent math, navigation, weight and balance, METAR and TAF interpretation, E6B relationships, checkride study, and connected flight planning. Flight-school and CFI resources are available at PilotDesk for Flight Schools.

How the tools are checked

Calculator formulas are kept in testable source files and representative calculations are checked automatically before production changes are accepted. Site checks also cover calculator-page generation, local links, structured data, accessibility-related markup, search metadata, and regression cases. Formula explanations and source notes are shown on calculator and guide pages so results can be traced back to the relationship being used.

Read the Editorial, Testing & Corrections Policy and Sources & Methods for more detail.

Public project trail

PilotDesk maintains a public GitHub repository so the codebase, change history, and QA workflow can be inspected independently. View PilotDesk on GitHub ↗.

Check the controlling source

PilotDesk is a supplemental planning and training aid, not an approved source. Check aircraft limitations and performance against current approved data, and use current official sources for weather, regulations, procedures, NOTAMs, and flight information. If PilotDesk disagrees with a controlling source, use the controlling source.

Corrections and feedback

If something looks wrong, report it. Safety-related corrections take priority, and confirmed issues should be corrected in the source and covered by regression testing when practical. You can also suggest calculators, guides, or pilot tools that would be useful.

Accounts, local data, and ads

PilotDesk uses a mix of account-synced progress and device-local planning data. Daily and Written Prep progress follow a signed-in account; Pro accounts can manually back up aircraft and saved flights to the account and restore that snapshot on another device. Advertising helps support the free site, and aggregate product analytics are used to see which workflows are actually useful. PilotDesk does not need a pilot's name, tail number, route text, or search text in analytics to measure whether a feature works.
