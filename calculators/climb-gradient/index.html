Use the Climb Gradient to FPM calculator

Climb Gradient to FPM uses Gradient, Groundspeed to calculate Vertical speed, Gradient percent, NM/min. Enter values from the source that applies to the problem, calculate, then compare the result with a rough estimate before you use it anywhere else.

Inputs

  • Gradient — enter the value in ft/NM.
  • Groundspeed — enter the value in kt.

Formula

Vertical speed (ft/min) = climb gradient (ft/NM) × groundspeed (NM/min).
