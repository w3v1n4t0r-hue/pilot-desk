How to use this calculator

Use current pressure, temperature, and weather data. If the number affects a flight, check it against the aircraft performance information and current weather products you are using.

Enter Field elevation, Altimeter setting. The calculator returns Pressure altitude, Pressure correction, Field elevation. Check the inputs before relying on the result.

Quick check

The sample values are: Field elevation 1000 ft; Altimeter setting 29.42 inHg. Run the calculation, change one input, and run it again to see how the result changes. For a real flight, replace the sample values with current information and check the result against the applicable POH/AFM, chart, weather product, or navigation source.

Show formula and assumptions

Pressure altitude ≈ Field elevation + (29.92 − Altimeter setting) × 1,000.

Units are shown beside each field and result. Aircraft-specific corrections, interpolation rules, reserves, runway factors, and operating limits are not included unless the page says they are.

Common questions

What is pressure altitude?

Pressure altitude is the altitude indicated when the altimeter is set to 29.92 inHg. It is commonly used as an input to performance calculations and charts.

Why is the result an estimate?

The common field-elevation formula uses about 1,000 feet per inch of mercury. It is useful for planning math, but aircraft performance should follow the approved charting method.

What if the altimeter setting looks unusual?

Verify the source. PilotDesk flags settings outside a broad sanity range, but the warning is not a substitute for current weather or airport information.
